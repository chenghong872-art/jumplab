# JumpLab V3 模擬版

可直接開啟 `index.html`。包含安全確認、CMJ/SJ/DJ、FPS、側面影片匯入與預覽、剪輯與逐格時間軸、T/L 手動標記、滯空時間與跳高換算、最多 3 次試跳、複製結果、列印／另存 PDF、選手資料。

影片只在瀏覽器本機處理。本版本已加入瀏覽器端 MediaPipe Pose 姿態骨架與 AI 輔助辨識；T/L 手動標記仍保留作為複核。

## AI 與外骨骼

頁面現在可載入瀏覽器端 MediaPipe Pose，將姿態骨架疊加在影片上，並用雙腳踝位置估算起跳、落地、滯空時間與跳高。需有網路連線下載模型；若模型或影片格式無法載入，頁面會顯示原因。
